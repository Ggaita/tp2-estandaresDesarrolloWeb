
# Landing Page

Landing page personal desarrollada con HTML, CSS y JavaScript, utilizando Node.js y Express en back.

## Stack

- HTML5, CSS3 y JavaScript
- Node.js
- Express
- Font Awesome (iconografía)
- SweetAlert2: mensajes interactivos del formulario (muy conocidos)
- AOS: animaciones de aparición

## Requisitos

- Node.js
- NPM

## Instalación

Clonar el repositorio:

```bash
git clone https://github.com/Ggaita/tp2-estandaresDesarrolloWeb.git
cd tp2-estandaresDesarrolloWeb
```

Instalar las dependencias:

```bash
npm install
```

## Ejecución

Iniciar el servidor:

```bash
npm start
```

Abrir en el navegador:

http://localhost:3000

Para desarrollo:

```bash
npm run dev
```

## Estructura del proyecto

- `index.html`: página principal.
- `assets/`: archivos CSS y JavaScript.
- `images/`: recursos gráficos.
- `server.js`: servidor Express.
- `package.json`: configuración y dependencias NPM.
